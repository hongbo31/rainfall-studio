# 番茄专属窗口登录状态识别

2026-11-20

番茄官网可能在页面初次加载后跳转登录页。旧版仅在首次加载结束时核对地址，随后只等待 UID。遇到延迟跳转时，UID 读取超时，账号列表就显示灰点。旧版还会把未核实和待登录结果缓存三十秒，用户登录后可能要等下一轮缓存到期才变色。

账号管理现在通过各账号的专属会话单独核对。检测同时等待可见 UID 和官方登录表单，识别异步跳转、原地址显示的登录表单及未授权响应。已核实身份显示绿色，需要重新登录显示红色。专属窗口关闭时，灰点的提示和右侧状态显示「专属窗口未打开」。状态待核实时仍用灰色。待登录或待核对结果五秒后可重新检查，已核实结果最多缓存三十秒。

## 涉及文件

- `src/main/fanqie/catalog-session.ts` 更新读取信号、刷新时机、工作区作用域和会话关闭清理。仍通过同一账号的后台标签读取官网，检查完成即关闭该标签。保留已有工作页，也不自动操作登录表单。
- `src/main/bootstrap.ts` 在打开专属窗口时返回当前状态，已有资料仍可走原账号核对流程。
- `src/renderer/pages/PlatformAccounts.tsx`、`src/renderer/account-session.ts` 和 `src/renderer/components/PlatformCardHeader.tsx` 展示关闭或待核对状态。浏览器工作台和 Windows 客户端共用此实现。
- `tests/fanqie-native-adapter.test.mjs` 添加无头真实浏览器回归，模拟异步跳转、重新登录、原地显示登录表单和原工作页保留。

## 验证与回退

- 旧版回归复现 `unknown`。新代码通过延迟跳转转红、重新登录转绿及原地登录表单转红的回归。使用空白隔离配置访问真实番茄公开页面，确认程序返回需要重新登录。测试没有使用用户浏览器会话或正式账号。
- 91 项番茄离线测试、14 项无头浏览器测试及 3 项账号管理、平台管理、浏览器工作台测试通过。TypeScript 检查、`scripts/Start-Rainfall-Browser.ps1 -BuildOnly` 和 Windows Main、预加载、Core 与共用渲染层构建通过。用户账号的实际登录状态及 Windows 原生窗口待验收。
- 本次无数据迁移。需回退时撤回上述源码和回归改动，使用原启动入口重建预览。桌面版按现行验收策略切换。
