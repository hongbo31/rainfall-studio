# 番茄目录批次完成后关闭工作窗口

## 改动

番茄目录上传的最后一轮原先会退回创作首页，账号浏览器仍然开着。`src/main/fanqie/directory-run.ts` 现在先保存整批结果，再关闭本批使用的工作页和已核对的签约页。此账号窗口里的所有标签都属于本批时直接关闭窗口。有其他标签时逐个关闭本批的页面。

还有待执行歌曲时，工作页回到首页供下一轮使用。待签署、待核对和报错的窗口保留。选择「否，合同生成后继续」时，以合同已生成且回执核对通过为该轮完成条件。关闭失败会写入执行日志，已保存的批次结果可继续查看。

## 验证和回退

- `tests/fanqie-directory-catalog.test.mjs` 验证待核对和待签状态的窗口可用，最后一笔回执确认后关闭仅含工作页的窗口。
- `tests/fanqie-downloads.test.mjs` 覆盖分批生成合同、签署完成后的同源结果页，以及同一浏览器里的其他标签。
- 52 项相关回归、TypeScript 检查和浏览器预览构建通过。隔离的持久化浏览器测试验证关闭后仍保留账号配置目录。Windows Electron 本地桥接验证关闭后仍可查看批次结果和执行日志入口。
- 浏览器和 Windows 客户端共用这段收尾逻辑。测试使用隔离下载目录、合成作品和无头浏览器。真实账号流程和 Windows 原生窗口待验收。
- 回退时恢复本次列出的源码和测试，再重新构建。关闭操作只结束浏览器会话，已保存的批次与账号会话目录可继续使用。
