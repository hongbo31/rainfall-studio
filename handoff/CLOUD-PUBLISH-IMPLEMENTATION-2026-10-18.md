# 云端统一发布实现与验收边界 · 2026-10-18

## 结论

本轮已补齐可调用的统一发布编排、云浏览器准备/提交适配器、明确授权、单曲回执、持久防重复及只读恢复代码，并完成独立安全复查与离线验证。当前可交付的是源码补丁及可重复验证证据，**不是已经实站验收通过的发布版本**。生产默认页面契约仍为 verified:false，不能直接切成 true。

未操作原 90VC Windows 主机，未向腾讯上传/填表/勾选协议/正式提交，未重传《把晚安留在门口》，未推 Git、部署或覆盖桌面入口。该既有作品在统一入口和动态素材解析中明确禁止调度。

## 实际调用链

1. PublishCenter 的 publish.simple 先由 Core 校验材料、冻结快照并持久化 unified-publication 任务，再由 Main 调度。
2. 同账号、同音频的 QQ/酷狗选择合并；重复点击复用任务。素材变更、复制成另一首本地作品不能绕过已派发录音的防重复约束。
3. Main 依据当前作品、A 音频/封面/歌词/完整元数据及账号，选择唯一有效授权，不能凭歌名或任意同作品旧授权调度。
4. “投稿资料”可本地编辑，已有工作/平台默认带入；真实 AI 工具、日期、署名归属、翻唱许可等不编造。保存只改本地数据，不构成上传授权。
5. 动态范围不再依赖手工逐曲 JSON。只读检查不创建文件；用户明确同意准备后，已是 PCM 的 A 可生成本地校验副本，或采用有可信来源记录的已验证 PCM 派生。未实现任意 MP3 自动转码。
6. 账号检查生成一次性、5 分钟有效的确认 nonce。确认时重新检查完整材料、账号与浏览器绑定；任何变化要求重新查看和确认。动态授权的每次材料核验同时核对完整当前元数据。
7. Main 的云会话管理器实际接入 bootstrap 和准备/提交适配器；只在明确点击后连接现有 127.0.0.1 CDP 浏览器，不启动浏览器、不开启调试端口、不复制登录态。云绑定使用独立 session/page 字段，不伪造 Windows PID/HWND。工作区/模式/进程代际改变时解除旧会话。
8. 云准备器实现定位、一次音频选择、字段填写及读回、一次封面选择、仅本地专辑材料快照、前进条款预览。严格 URL 与可见页面标记双验证。未知裁剪/页面继续阻断；不接受协议、不点击正式提交。
9. 条款确认与正式提交仍走独立 submission 状态机；持久操作意图先于外部动作，单次勾选/单次提交，未知结果禁止重发。
10. 官方回执必须明确 entityType:song，唯一、匹配账号/标题/艺人/不可变提交意图及时间。专辑 ID 不能作为单曲 ID。列表、点击成功或本地计数均不构成正式成功。
11. 提交后的新会话只读核对允许重新连接并匹配官方单曲回执；不放宽上传、接受或提交的绑定要求。断网/中断后的准备任务保持保护状态，必要时需人工核对既有页面，不能自动重传。

## 独立审查修复

- 修复“检查账号 A，确认前切换成 B”的错绑风险。
- 修复“授权后改署名/许可，但仍上传旧元数据”的风险。
- 修复准备已完成、预检暂时失败后没有只读恢复入口的问题。
- 修复云适配器只有工厂、生产 bootstrap 没有会话接线的问题。
- 修复首次阻断与重启后未知任务没有连接入口的问题：连接按钮独立于准备授权，所有发布进度状态可访问。
- 修复新会话不能核对既有正式提交回执的问题。
- 最后一次只读复审未发现上述变更残留 P1；这不替代真实平台验收。

## 实站仍需的最小范围

只读观察已经确认 AI 起始页路由、唯一上传 input、两步骤及发布列表中专辑链接；尚无上传后的元数据、完整身份指纹、条款、裁剪、正式提交和真实单曲 ID 的校准证据。因此默认正式执行仍关闭。

下一步需选择一首从未上传/提交的 AI 原创测试作品 A，不能使用已发布旧歌或 B/翻唱：

- 符合官网规格的音频；为缩小首次验证范围，优先提供已验证 PCM WAV（官网当前提示至少 60 秒、低于 200M）。
- 封面、最终歌词与对 A 的匹配确认。
- 实际标题、署名/归属、AI 工具和生成日期、专辑资料、权益和是否允许翻唱的明确选择。
- 目标为用户核对的腾讯账号；完整官方身份需在可见页面独立验证。
- 第一段仅授权将这些材料发送至该账号、填写资料、设置封面、前进到条款预览，可能形成平台草稿。遇到未校准弹层/权限/费用或协议立即停下。不得接受条款、签约或正式提交。
- 拿到真实条款与提交阶段证据后，再单独确认具体协议及是否正式提交。届时仅接受匹配本次单曲的真实回执。

需要的浏览器必须在本次获准的云执行环境可连接；不能把 dot 的浏览器登录成功等同于应用已取得 CDP 连接，也不能擅自开启调试访问。原 Windows 主机不在范围内。
