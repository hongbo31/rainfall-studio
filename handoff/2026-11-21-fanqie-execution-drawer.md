# 番茄音乐执行窗口

原执行窗口会在有待核对批次时禁用两个设置，并在重新扫描时覆盖手填值。现在「每批上传上限」和「是否签约」放在发布账号下方。等待核对期间可以编辑，重新扫描保留输入。「下载目录歌曲」紧接在「最近一批投稿」上方。

点击「核对并继续下一批」时，把所选上限和签约选项写入该账号当前批次的未上传队列。已提交的批次按开始执行时的签约设置核对，账号默认值仍由账号管理保存。旧批次缺少单轮签约设置时，从原批次设置读取。

待核对批次还有未上传歌曲时，发布确认框可以勾选。勾选后使用正下方的「核对并继续下一批」，先核对已有投稿，再处理剩余歌曲。改动上限或签约选项后需重新勾选。

批次处于「需核对投稿」且显示 0 首待处理时，上方原来会隐藏执行按钮。现在在同一位置显示「核对投稿状态」，方便先核对上一批，即使正在修改每批上限也可进行。核对完成后，上方恢复「执行上传」，发起新上传仍需勾选发布确认。

## 涉及文件

- `src/renderer/components/FanqieDownloadUpload.tsx` 和 `src/renderer/platform-management.css` 调整布局、输入和重扫行为。
- `src/main/fanqie/upload-broker.ts` 和 `src/main/fanqie/directory-run.ts` 校验下一批设置、批次 ID，并沿用当前投稿的签约设置完成核对。
- `tests/platform-management-ui.test.mjs` 和 `tests/fanqie-downloads.test.mjs` 覆盖待核对时编辑、重扫保留、界面顺序、上限校验、按新设置续传及 0 首待处理时恢复执行入口。
