# 番茄间歇性艺人选择失败

2026-11-27，第 83 次番茄目录上传出现 `FANQIE_AUTHOR_DETAILS_CHANGED`。第一份用户 HTML 显示活动词作者下拉候选“锤锤家”仍未选中；后续单独提供的弹窗 HTML 则确认详情弹窗可以正常出现：`role="dialog"`、`aria-modal="true"`、标题“艺人详情”、资料名“锤锤家”和按钮“确认选择”。第一份整页快照未包含 portal 弹层，因此不能据此断言详情弹窗没出现。

## 根因判断

- 番茄候选 DOM 是多选控件：候选 `li[role=option]` 内有选择复选框，艺人行还有单独的右箭头详情入口。旧代码对普通词/曲作者点击全页候选的 `li`，对有 ID 的歌手点击候选内部行；点击目标不统一。
- 用户补充的独立弹窗 HTML 证实“艺人详情”及“确认选择”实际出现。进一步检查确认，确认前代码两次分别调用 `artistDetailDialog(page)` 创建了不同的 Playwright `Locator` 对象，却用 `ready.detail !== detail` 比较对象引用；该条件对两个独立 Locator 恒为 true，即使它们定位到页面中的同一个弹窗也会误报 `FANQIE_AUTHOR_DETAILS_CHANGED`。这比“弹窗没出现”更直接地解释本次停止。
- 弹窗内容异步渲染也可能造成短暂读值不一致；歌手 ID 分支还必须等待详情歌曲列表 API 响应，而非请求刚发出。第 83 次没有完整 trace，无法确定该次究竟在哪一条旧检查上触发，但新增 HTML 与这个恒真引用比较共同确认了确认阶段存在确定性缺陷。

## 修改

- 通过当前署名 combobox 的 `aria-controls` 精确定位其 listbox 和唯一候选，避免全页同名候选干扰；仅在 combobox 展开时处理候选。
- 所有署名都点击候选详情箭头，等待官网 `artist-detail-modal` 的标题、`.artist-info .artist-name` 和 `.confirm-button` 文本精确匹配后才确认；等待期间容忍异步内容渲染。
- 以弹窗 `aria-labelledby` 值核对确认前仍是同一个详情弹窗，移除对两个新建 Locator 对象做引用比较的错误判断。
- 传入 `singerArtistId` 的歌手等待 `get_song_list` 响应完成，再核对响应请求的 `artist_id` 与预检 ID 一致；不再将请求刚启动当作资料已经加载。
- 确认后仍等待并核对当前字段唯一的艺人标签。重名、ID 不匹配、候选控件变化、详情资料或读回不匹配时安全停止。

## 执行日志增强

艺人选择 trace 的 `details.artistSelection` 现在记录阶段、署名角色与目标名；搜索阶段记录输入读回、下拉展开状态、候选数量和各类重试次数；详情阶段记录可见弹窗数量、`aria-labelledby`、标题/艺人名/确认按钮数量与文本、按钮是否可用和等待耗时；歌手 ID 核验只记录响应是否收到、HTTP 状态及 ID 是否匹配，不写入实际艺人 ID 或请求 URL；确认阶段记录是否点击、弹窗是否关闭及表单读回的艺人名。`safeDetails` 对字段做枚举校验、字符串长度限制和控制字符清理。用户可从番茄执行记录的“打开执行日志”查看对应 `trace.jsonl`。

## 2026-11-27 追加：候选异步加载与搜索词意外清空

用户最新 HTML 显示词作者搜索框 `value=""`、下拉仍展开，精确候选“锤锤家”处于 `aria-selected=false`。这说明候选仍可见时搜索词已经丢失；慢加载或 React 重绘是可能诱因，但快照不足以确认唯一根因。旧逻辑只核对下拉候选数量，没有在点击详情箭头前再次确认查询词与候选状态一致，因此会把空搜索/陈旧候选送入后续流程。

- 候选读取现要求搜索框精确等于目标署名、当前 `aria-controls` 下拉展开、字段尚未出现已选艺人、唯一精确候选和详情箭头同时存在，并连续稳定至少 500 毫秒；点详情箭头前再执行一次同样的核对。若候选已被点成已选状态，会记录标签并暂停，避免重复选择。
- 若读回词为空或变化，会限次重新填入署名并等待候选；下拉意外收起时会重新打开搜索下拉。仍无法稳定时按输入未读回或加载超时停止，不再根据“没有候选”推断艺人不存在。
- 日志新增实际搜索框读回、是否为空、详情箭头数量、稳定时长、补填次数、下拉重开次数和意外已选标签；署名子步骤会把结构化诊断写入当前歌曲序号对应的 trace。超时提示要求核对歌曲序号、署名、搜索框读回和候选数量。

## 2026-11-27 追加：候选行可见但未进入选择流程
