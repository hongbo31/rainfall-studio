# 苏诺之音可选提交校验后歌词确认

日期：2026-11-24（北京时间）

## 原因与改动

根据 susu 提供的截图和粘贴的苏诺之音 DOM，点击自定义模式“创作”后，页面可能异步出现“提交前歌词校验”弹窗，右侧操作为“提交校验后歌词”。`runSunoCnBrowser()` 之前只识别“提交原歌词”，可能没有选择校验后的版本。

- `src/main/suno-cn-browser-page.ts`：提交后最多观察 20 秒；若歌词校验弹窗内唯一可见的“提交校验后歌词”按钮出现，则点击后再进入原有生成结果校验。20 秒内没有出现便继续现有歌词按钮、积分/人声提示及歌曲结果检查。
- 若出现多个同名目标按钮则停止并报 `SUNO_CN_LYRICS_CONFIRM_AMBIGUOUS`，避免误点。点击失败且按钮仍在时返回现有歌词确认错误。
- 等待时间作为 `lyricPreflight` 默认 20 秒参数，保留浏览器模拟时覆盖该时限的能力。
- 该入口由苏诺之音自动化任务和计划执行共用；没有改变原歌词路径、生成次数、回执核对、作品文件或番茄上传。

## 验证与影响

- DOM 选择器和准确按钮名称依据用户提供的截图及 DOM 片段。
- 未添加或运行测试、未构建；未启动可见客户端/浏览器，未操作真实账号或触发收费生成。
- 变更在 Main 侧浏览器自动化中，任务中心关联计划和苏诺之音独立自动化共用该函数。Windows 客户端使用同一实现；未做 Windows 原生 UI 验收。
- 每次创建提交后最多增加 20 秒等待，用于处理可选弹窗。若弹窗较早出现则立即点击，不等待剩余时间。

## 后续与回退

- 后续隔离浏览器回归应覆盖：弹窗立即出现、延迟出现、20 秒未出现、点击失败和多个同名按钮；再做 Windows 客户端原生验收。
- 回退时移除 `lyricPreflight` 等待和对应交接记录即可，其他生成/下载改动保持不动。
