# 番茄新艺人歌手 ID 核对

2026-11-27，第 80 次目录上传在歌手下拉框能显示新艺人名称时仍报 `FANQIE_SINGER_ID_UNVERIFIED`。

## 根因

- 批次预检已从番茄艺人列表接口读取唯一名称对应的远端 `author_id`；上传表单也能按名称显示艺人。
- 表单选项阶段又依赖 React 私有 `__reactFiber$...` 属性，在固定 6 层父节点内提取 `artist.id`；已选标签阶段还依赖 Fiber key 解析 ID。艺人姓名正常显示时，页面 React 节点结构仍可能不符合该私有读取假设，因此代码在未点击下拉候选项前就误报 ID 无法核对。

## 修改

- `src/main/fanqie/directory-form.ts` 移除对 React Fiber 内部属性的读取。若歌手名有多个可见选项，则按歧义安全停止；唯一精确名称项可进入艺人详情。
- 点击候选项时监听官网歌手详情请求，核对其 `artist_id` 与批次预检拿到的 `author_id` 完全一致，匹配后才显示“确认选择”并确认；之后读取歌手标签精确名称，并在本次批次条目上记住已核对 ID。
- 歌手缺失、详情请求 ID 不匹配、详情请求超时或同名候选不唯一时仍停止，不会仅按名字盲选。

## 验证边界

静态核对了用户截图（歌手搜索下拉框已显示“锤绵绵”，但尚未选中）、代码中的歌手 ID 来源、表单详情请求和确认顺序。已检查差异格式；未运行测试/构建，未访问官网账号、重新上传歌曲或更新/重启客户端。

## 回退

仅回退 `directory-form.ts` 中歌手候选与详情请求核对逻辑以及条目内 ID 确认标记；保留其他目录上传、封面和歌词修改。
