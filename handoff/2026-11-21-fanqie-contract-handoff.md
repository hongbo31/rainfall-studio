## 改动

- `src/main/fanqie/directory-signature.ts` 与 `directory-run.ts` 核对当前批次授权页打开的签约标签。支持可见的「数据安全验证」，也支持带有签署控件的「文件签署」。识别离开预览、签约链接未生成、生成后返回预览或等待超时。离开预览时提示从已上传的作品继续签约。第三方页面日志保留错误码，签约链接和验证码留在官网。
- `src/shared/fanqie-downloads.ts` 与 `src/renderer/components/FanqieDownloadUpload.tsx` 显示等待本人确认、合同生成、待打开签约页及等待签署四个阶段。官网提供「跳转授权」时给出入口提示。
- 自动续跑需要本批相同作品 ID 和标题已进入审核或已上架的官网回执。签约标签的观察结果和回执各自核对。应用重启后可查原批次，保留已上传的作品和待签状态。旧批次在没有验证页证据时保留下载材料。

- `tests/fanqie-downloads.test.mjs` 用无头 Chromium 覆盖两种签约页、未生成链接、同名帮助页、独立打开的标签、返回发布页后保留原批次、生成后返回预览并保留截图，以及同一作品进入审核后只执行剩余一批。`tests/platform-management-ui.test.mjs` 核对执行窗口的本人确认提示与已有批次的核对入口。目录和界面回归 27 项、番茄回归 116 项及 TypeScript 检查通过。
- 浏览器预览与 Windows 客户端共用上传逻辑。原浏览器入口构建和 Windows Electron 无窗口桥接验证通过，旧批次可显示合同状态和签约错误。真实账号签署、Windows 原生窗口和正式打包待验收。
- 当前批次从番茄「成品发行 → 待授权」找到已有作品。官网显示「前往签约」时可打开已有合同，显示「修改作品」时可从该作品继续授权。本人完成签署和验证后，回执行窗口点「核对投稿状态」。如果仍在官网的合同流程，且显示「已跳转签约页」，可用「跳转授权」。浏览器新版使用原 `Start-Rainfall-Browser.bat`。回退时恢复本轮源码与测试，保留作品库、已上传批次和官网回执。
