# 雨序 Rainfall Studio — 需求与验收

目标：为个人原创音乐创作者串起故事、歌词、音乐生成准备、作品版本、封面、发布材料和统计；预留多账号/团队扩展。首阶段仅本地交互，不绑定账号、不真实生成扣费、不发布、不进行第三方通信。

## 信息架构
总览（预算/系列/作品/队列）→ 创作向导（声音参数、故事、模板歌词/提示词、版本）→ 作品详情（A/B 真实本地音频导入、歌词对比、授权备注）→ 封面工作室（提示词、Codex 手动任务、图片导入、历史版本、歌名/艺名、PNG 导出）→ 发布中心（音频与抖音视频分型、材料预览、本地审核演练）→ 数据看板（CSV 来源与日期）→ 账号设置（身份状态、预算、备份恢复）。

原创样本：《那天刚好下雨》《顺路》《从今天起》，系列“雨的三种时态”，相识/熟悉/告白。文本由本项目编写；不含他人歌曲或音频。没有音频时不能播放。图像为 CSS 原创程序占位，不冒充 AI 生成。

## 首版验收
- 七页面可点击；中文表单覆盖风格、语言、男声/女声/对唱、情绪、节奏、时长、故事。
- 歌词可编辑/保存快照并比较；音乐提示词可编辑。模板输出标注非模型生成。
- 同作品/平台/歌词/声音参数任务去重；模拟失败可原任务重试；所有模拟任务成本为零。
- 音频 A/B 分别本地导入并实际播放，不保存音频到浏览器存储；刷新后需重新导入。
- 封面提示词复制为 Codex 人工辅助任务；无图像 API 假承诺；导入版本持久化并可选用；导出方形母版或竖版草图。
- 发布材料按平台和内容类型预览；模拟审核/驳回明确显示演练原因；不显示已真实发布。
- CSV 导入校验与平台/日期去重；零数据为空状态；备份下载和恢复可用。
- localStorage 保留文本、预算、封面、队列、审核、报表；所有界面输入转义后渲染。

## 明确限制
系列故事线首版为三章固定演示，非完整系列/专辑编辑器。账号是未绑定状态展示和数据结构预留，不实现 OAuth/团队权限。队列为本地同步状态机，不后台运行。歌词版本对比为左右全文，不提供逐字差异。额度仅计划预算，非服务商剩余额度。封面预设不是平台当前官方规格保证。音频、封面等素材暂没有完整文件级版本存储与授权文件上传；授权依据为文本备注。报表仅 CSV 汇总，未做平台自动抓取。
