# 0.12 三类生成配置、艺人与账号身份

本轮在独立项目 rainfall-studio-unified-acceptance-20261018 实现，不改变正式 0.11.2 入口。个人创作者为默认，多账号独立映射保留团队扩展空间。

## 信息架构与实现

- 配置中心 / 模型 API：歌词与提示词、封面图片、音乐生成三个分组；每组独立默认配置。配置含提供商/渠道、模型、版本、凭据引用，Key 仍由 Main 的 Windows 安全存储管理。
- 创作中心：单次创作使用与计划相同的 Core → Main provider broker 管线；默认或覆盖三类配置，明确授权文本额度，未授权也可保存并查看阻塞项。
- 计划中心：选择艺人、安排时间、选择本地/同步文件夹、设置每次故事与阶段、生成路由和发布身份映射。目录请求只引用已确认计划，不能夹带授权或凭据。
- 艺人资料：语言、人声、曲风、BPM、乐器、歌词语气、封面风格和系列长期故事线；Core 保存时冻结艺人修订。每次 storyBeat/storyStage 单独保留，实际提供商 prompt 使用冻结上下文。
- 封面工作室：从可信计划 workId 所属关系读取图片路由，覆盖音乐生成作品；本地导入和 dot 外部出图都不是直连图像 API。图片 API 待接入配置保持关闭。
- 平台配置：显式“绑定账号”“核对登录状态”入口。远端账号和艺人 ID 必须由内部已验证适配器读取；用户确认本地映射。名字、页签或旧组合指纹均不能自证绑定。

## 状态与约束

新任务冻结三类 profile ID/revision、provider/channel/model、凭据引用和艺人版本。改默认不改运行中任务；旧计划需编辑重审。配置变化、模型不匹配或不可用能力会阻塞。请求 ID 重放返回同一任务，变化内容拒绝。文本结果经真实管线的版本/评分证明后保存到作品库；没有音频就不显示生成音频成功。

绑定关系与登录状态独立：bound/pending/revoked；valid/unchecked/expired/identity_mismatch。登录有效证据只存服务实例内，客户端重启必须重新核对。新路由任务在首次入队、后续上传/提交的每次 write claim 前核对完整冻结身份；缺映射、错艺人、撤销、过期均阻塞。原提交 intent 已存在则先只读对账，不以重登录为由重发。

旧 profiles、Key 引用、本地预算、旧计划和去重 intent 不自动迁移身份，也不改旧 familyKey。历史作品、播放 A/B、发布预览与主题保持。

## 真实接入边界

- 文本：DeepSeek/豆包的 Main 适配器已实现；本轮不使用真实 Key，不调用收费模型。完整生成/评分验证使用明确标记的离线响应夹具。
- 图片：本地导入、dot/外部会话结果导入；图片 API 关闭。没有免费 Codex 图像 API 的承诺。
- 音乐：已安装 YourMusic 第三方协议路径保留；渠道与底层模型分别记录，实际账号/报价/模型可用性未核实。不能声称这是 Suno 官方 API，也不能据此猜测谱乐 AI 待提供网址。
- TME：身份状态核心和入口已实现；当前 reader 只有酷狗绑定 ID、QQ 昵称和艺名，缺稳定 TME/QQ 账号 ID 与远端艺人 ID，生产绑定保持未接入。打开新的持久授权会话不是本轮自动动作。
- 网易云、汽水、QQ/酷狗、抖音各能力分开，绑定不等于上传或提交可用；抖音视频与音频发行分开。详见接入矩阵。

## 验收

新增路由/实际 Main 夹具链、绑定状态机、跨进程重启、发布写门禁的离线测试；原计划、目录、评分、准备/提交与未知结果回归；构建和类型检查。隔离候选在真实 Windows 可交互桌面检查三组配置、艺人、单次任务、计划原生目录选择、绑定缺项和两主题；保留截图、具体路径和实际结果。正式入口不自动提升。

真实 TME 绑定与“客户端重启/外部浏览器重启后身份保持”仍需先校准官方会话身份来源，再由用户确认映射。本轮不得以离线状态机测试代替真实会话验收。
