# 番茄第一步表单准备模块（90VC）

基线：本机 `rainfall-studio-unified-acceptance-20261018`，0.12.0-preview.5，HEAD `a50dc316bf13cbc2ffb8df31e82fc4eff7aaf8e0`。本轮实现位于当前任务的 `rainfall-fanqie-preview5` 隔离副本，未改变原仓库、桌面入口、运行包、歌曲、素材或账号数据库。原仓库两份未跟踪验收文档保留。

## 真实页面证据

受支持的 Edge 工具重新认领现有标签后恢复读取。主页显示“栩你看海”；该名称不是已验证的稳定账号或艺人 ID。成品发行列表全部/待授权/审核中/已上架/未通过/已下架均为 0。空表单依次为上传歌曲信息、授权签约模式、预览合同协议；本轮仅展开第一步的一张空歌曲卡片。

已看到音频 wav/mp3、至少 44.1kHz/16bit/双声道、时长大于 30 秒、最大 200MB；TXT 歌词最大 1MB；作品名最多 40 字；词作者/曲作者/歌手；方形封面至少 1440×1440、最大 10MB；AI 声明默认否但须按实际制作方式明确指定。作者候选框暂无匹配艺人。未看到专辑字段；多歌曲卡片不能当作专辑能力。

展开后的 DOM 没有文件输入框，因此不预设隐藏 input 选择器。没有上传、填写真实歌曲、保存草稿、创建艺人、选择授权模式、接受合同或提交审核。

## 实现边界

- `src/shared/fanqie.ts`：独立类型、能力及阶段。准备、上传中、未知结果、合同待确认、已提交、审核、上架分别表示；真实上传、草稿、提交及专辑能力均保持 false。
- `src/core/fanqie.ts`：校验真实文件哈希、FFprobe 音频属性、Sharp 图片尺寸和 UTF-8 歌词；AI 属性必须显式指定。MP3 无可靠 PCM 位深证据时停止，不能仅凭扩展名放行。
- 准备日志使用独立 settings 命名空间，按账号/艺人/录音哈希去重；材料指纹固定；每次外部写之前持久化，CAS 阻止并发覆盖，重启将进行中记录变为 unknown。未知操作只读核对，不自动重试上传。
- 浏览器接口只定义受注入端口。超时后允许端口执行受支持的重新认领并重读，不重放写动作。离线夹具明确标记且不能转成生产证据。生产浏览器端口尚未安装，入口主动拒绝。
- `src/main/fanqie/form.ts`：只读表单探测；文件选择辅助器先等待 filechooser，再点击已校准的唯一角色控件，传文件前再次验证范围和字节；作者框要求唯一歌曲区域及已验证角色区域归属。没有猜测 DOM 选择器或新增 CDP/HTTP/浏览器档案通道。
- Studio snapshot、发布中心和生产队列呈现不可自动发布状态；番茄任务禁止 claim、promote 或复用腾讯签约流程。没有开放 renderer 上传 API。

## 后续所需

用户已指定《给明天多摆一双筷子》，并明确确认作词、作曲、歌手均为“栩你听海”，署名不再待确认。本机仅有 model_pending 文本候选和 1254×1254 封面，无对应音频或生成任务。需补齐合格音频、至少 1440×1440 封面，并核实 AI/权属、稳定番茄账号与各角色对应的艺人身份、唯一角色区域、上传控件和回显，才能安装生产端口。角色同名不代表平台身份 ID 相同，读取到显示名不足以放行。生成费用和后续实际合同仍须核实；既有已手工提审作品不得重放。
