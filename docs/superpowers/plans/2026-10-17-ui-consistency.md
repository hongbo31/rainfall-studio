# 全局界面一致性整理

基线a527881（已交付程序94da503/0.8.0-preview.1）。用户明确要求直接实现，不重复确认；仅后台，不打开可见窗口或自动重启。目标0.8.1-preview.1。

## 统一规则

- 使用同一系统中文无衬线字体；正文/控件14px，辅助12px，标题28/18/16px，字重400/500/600。
- 普通按钮、输入框及select40px，图标帮助28px；顶栏状态/切库/备份三项统一36px、13px字体、12px水平内边距，状态保留色彩语义。
- 8px基础间距，表单间隔16px，卡片内边距20px；主次按钮保留颜色层级，checkbox/radio保持16px。
- 样式入口统一为有序CSS层，最终系统层明确覆盖旧零散控件字号，保留封面画面及业务状态配色。
- 常驻名称、简短状态和可行动错误。解释放可键盘访问HelpNote/HelpHint或关闭详情；费用、协议、权限、未知结果风险保持操作处可见。
- 作品库简洁标题、筛选栏、创建按钮、卡片播放及系列表单一起检查；全局英文装饰标题移除。

## 执行与验证

1. root统一context/main/CSS，另一个文件边界独立的文案任务整理pages/components；不改core/main进程/数据接口。
2. 真正headless Chromium读取实际构建renderer，用隔离演示快照与阻断bridge；先验证现有顶栏不一致失败，再实现并检查计算样式、无溢出、全部导航、键盘帮助及主要表单。
3. 原UI回归、集成、类型、基础测试和构建；独立审查相关diff。
4. 便携打包；仅满足后台验证及数据/回滚门槛后更新同一入口，绝不自动启动。不能完成的原生窗口视觉/播放验收明确列出。
5. 输出页面清单、无头截图、真实路径、测试证据和未完成验收项；不把演示快照和无头渲染称真实桌面验收。
