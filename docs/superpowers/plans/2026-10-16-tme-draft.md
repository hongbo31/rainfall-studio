# Tencent Draft MVP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox tracking.

**Goal:** Build a recoverable, account-bound Tencent musician draft workflow without submitting for review.
**Architecture:** Core owns persistent snapshots/checkpoints, Main owns the browser UI port and identity checks, renderer owns explicit metadata/lyric confirmation. Production mutation stays blocked until live page calibration and user-selected material/account are available.
**Tech Stack:** Existing Electron / React / TypeScript / SQLite / playwright-core; reuse installed dependencies only.
**Spec:** `docs/integrations/tencent-draft-design.md`

## Global Constraints

- Independent branch from clean published f6b2e08; local commits only, no push or EXE.
- Use the verified PowerShell 7 runtime and 90VC only; never restart user applications.
- No cookies/token extraction, private APIs, CAPTCHA bypass or new software installation.
- User must select real materials/account; no real upload in this phase.
- Ownership/author/AI/audio-lyric alignment require explicit current confirmation.
- Production page contract is unverified; future review submission remains disabled.

## Review Focus

- Identical recording with changed metadata must not bypass duplicate protection (Task1).
- A crash between external upload and local checkpoint requires reconciliation, never blind retry (Task2).
- Page identity changes between any two steps stop execution (Task2).
- Original bracketed lyric content must not be silently removed as a generation instruction (Task1).
- Restoring a backup cannot restore browser execution authority (Task1/3).
