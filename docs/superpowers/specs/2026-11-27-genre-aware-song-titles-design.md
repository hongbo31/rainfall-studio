# 曲风感知的动态歌名设计

## 意图

降低生成歌名的普通感和重复率，同时让 AI 作词结果里的“歌名一、歌名二”像自然、能独立成立的作品名。曲风线索可作为可选短描述；乐器和制作术语不得进入歌名。有单独风格描述字段时留在该字段，没有该字段时省略这些细节。

## 目标与边界

- 覆盖 AI 作词结果中所有歌曲类型的 `title`、`alternateTitle`（人声歌曲和纯音乐一并优化），以及歌曲灵感中的歌名生成；沿用现有字段与双端共享 Core 流程，不把歌名自然度规则限制在纯音乐分支。
- 模型先从本首歌词/灵感、故事场景和情绪提炼核心歌名，再感知曲风、演唱形态和内容，为核心歌名动态添加零到多个描述词。可选词包括曲风/形态（如 DJ、纯音乐）、氛围/用途（如助眠、空灵）以及年份/流行感词（如 2027 年、爆款）；不要求每首都添加，也不把任何一组词或词序固定下来。
- 歌名保持“核心歌名在前、动态描述在后”的可读结构，描述词组合、数量和词序按歌曲变化；描述词可以全部省略，即使 `style` 中明确出现曲风词也不要求标题必须带标签。“爆款”和年份可由 AI 按歌曲风格自由选择，不需要创作/发行信息提供依据；但不固定某个年份，也不要求每首歌都使用。
- 核心歌名要同时符合歌词/创作内容与音乐风格，读起来像自然的作品名，而不是独立于歌曲语境的抽象词或风格说明。人声从歌词主题、记忆句、动作或具体意象提炼，并用曲风影响措辞和氛围；纯音乐从本首音乐主题、旋律、节奏或可感知声景获得灵感。所有类型的候选歌名都不要直接使用乐器名、音色标签、编曲技法或制作说明作为标题，例如“纸页翻动时的雾感合成器”；当前任务有单独 `style` 字段时将这些细节留在 `style`，没有该字段时省略。
- “蹦跳墨尔本”可以单独作为核心名，也可以按歌曲自然地组成“蹦跳墨尔本DJ”“蹦跳墨尔本纯音乐”或含“爆款/年份”的动态标题。后续描述可有零到多个，但不为堆关键词而拼接；“爆款”和年份可按曲风自由选用，不固定、也不强制。
- 例如核心名“蹦跳墨尔本”可生成“蹦跳墨尔本2027年爆款DJ纯音乐”“蹦跳墨尔本爆款DJ纯音乐”“蹦跳墨尔本纯音乐”或“蹦跳墨尔本爆款”。这些是可选组合示例，不是模板或承诺每首带“爆款”。
- 避免通用抽象词、同义改写、编号和重复堆词；不要为了营销描述牺牲歌曲本身辨识度。
- 将同批已生成标题与同艺人最近 50 个作品的标题作为避重线索。近期记录只携带歌名，不读取歌词、素材、账号或外部数据。
- 保留现有标题清理、长度、语种和 A/B 差异规则；不改写历史作品、不增加 UI、不自动增加模型调用或费用。

## 方案

1. **作品名优先、描述可选（用户选择）**：核心名同时贴合歌词/创作内容与音乐风格，模型可根据曲风和内容附加零到多个短描述词。纯音乐的乐器和制作细节只作为核心意象的灵感，禁止把这些术语直接放进标题；有单独 `style` 字段时写在那里，没有时省略。这种方式优先自然度，同时支持用户给出的动态 DJ/纯音乐/氛围/年份示例。
2. **标签优先**：更常把 DJ、纯音乐、爆款、年份等并入标题，识别度和分类信息更直接，但标题容易像标签或宣传文案，核心作品名会被挤压。
3. **曲风词库拼接**：按风格维护关键词池并组合模板。可控但需要人工维护，且容易让同类歌曲标题同构。

## 仍由实现者决定

- 同批标题通过现有计划工作流上下文传递，不扩展作品持久化结构。
- 查询同艺人近期作品时只读取最多 50 个标题，按作品创建时间倒序；无法判断创建时间的旧记录不进入近期列表。
- 不追加收费重试。若模型忽略避重提示，仍沿用当前校验和人工核对路径。

## 验收

- 不同风格的生成请求都携带本首的风格/内容上下文；输出保留核心歌名并可动态添加零到多个曲风/氛围/用途/年份描述，DJ、纯音乐、助眠、空灵、爆款和年份均可省略，不成为强制后缀或固定词序。
- 人声与纯音乐的两个候选都要贴合本首歌词/创作内容及音乐风格。纯音乐可由乐器/音色/制作细节启发，但标题不直接复述乐器名称或编曲说明；有 `style` 字段时这些信息留在 `style`，没有时省略。不能产生“纸页翻动时的雾感合成器”一类制作描述式标题。
- 描述词可多可少或完全省略，即使 `style` 出现曲风词也不强制加标签；不得堆叠成标签串。“爆款”和年份可由 AI 按曲风自由选用，不能因示例而固定添加相同词或年份。
- 对“蹦跳墨尔本”一类核心歌名，提示允许产生用户给出的多种描述组合，同时禁止把“2027年爆款DJ纯音乐”固化为所有歌曲的模板。
- 同批及同艺人近期标题可作为明确的避重上下文，标题字段和既有历史兼容。
- 不引入额外付费请求；变更适用于浏览器预览和 Windows 客户端共用的 Core 逻辑。
- 静态检查，不调用真实付费文本 API，不启动可见客户端；未做真实模型表现或原生窗口验收。
