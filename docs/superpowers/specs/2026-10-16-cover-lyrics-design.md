# 封面交接与歌词发布设计

目的：个人创作者把歌曲上下文交给 dot 辅助出图，接回真实图片并选择封面；音乐生成时保存歌词来源和版本，发布材料携带歌词与封面。最初以隔离夹具设计；随后用户提供《从今天起》音频、歌词及父会话真实生成封面，已用于隔离客户端验收。用户另行授权现场腾讯音频上传和保存草稿；未授权审核提交或代选署名、AI 与签约事实。现场进度及软件接入边界以[本次验证](../../release/cover-lyrics-verification.md)为准。

这是现有流程的跨层扩展。采用既有 Core/SQLite/受管素材/React/Electron 分层，复用封面版本选择及文本 inbox 的规范化哈希。文本 inbox v1 保持原协议；图片采用独立 `cover-result` 清单，由用户选择文件导入，不增加监听器或第三方通信。相比直接新增付费图像 API，这条路径不需要凭据；相比只有手动图片导入，它能验证歌曲与请求归属并防重复。

## 封面请求和结果

- `cover.request` 固定工作区、workId、requestId、上下文哈希、提示词和本地状态 awaiting_result。上下文含歌名、艺名、歌词、故事、曲风与视觉方向。相同 requestId/输入幂等，改输入必须新请求；重生成保留旧结果和当前选择。
- 图片接口能力显示未配置，dot 路径显示文件交接。客户端不能调用当前 dot 聊天。导出 JSON 请求供人工带到支持出图的会话；真实文件到达后才能标记 received。生成来源是外部清单的声明，不冒充认证证明。
- 清单包含 schemaVersion、kind、workspaceRef、workId、requestId、contextHash、resultId、图片 basename/SHA256/MIME/宽高、producer/model/generatedAt。图片必须位于清单旁，禁止路径穿越/符号链接/网络路径；不下载 URL。
- 支持给选中请求直接导入真实图片，来源显示 user-import，生成时间未知。对所有结果验证 PNG/JPEG/WebP、完整解码、最多50MiB、方形512–10000像素、最多100MP；3000方形为工作目标，不冒充平台强制规格。
- 清单重复按请求/结果身份及内容哈希返回原回执，冲突拒绝；错工作区/歌曲/请求/过期上下文拒绝。导入只增加该歌曲的历史候选，不自动替换选定封面。选择前检查受管文件，发布使用明确选中的版本。

## 歌词原文与来源

- 作品歌词原文保存在不可变版本中，记录 manual、generation_input 或 provider_actual 来源、提供方输出身份和版本。未返回实际歌词时只能保留生成输入并提示待核对，绝不把音乐提示词当歌词。
- 音乐 operation 固定提交歌词快照，候选保留该快照。适配层可返回规范化 actualLyrics；没有核实外部接口字段时不猜字段映射。选定候选优先保存实际返回歌词，否则保存生成输入及其来源。
- 旧作品可编辑及导入 UTF-8 TXT，编辑产生新版本。发布预览只移除独占一行的已知英文/中文结构标签，保留重复副歌、演唱文字、空行、未知括号内容并警告；保留原始换行原文，不生成时间戳。
- 用户确认绑定歌词版本、纯文本哈希及所选音频哈希；编辑歌词或重选音频后失效。
- 腾讯正式歌词与作品清理稿不同时，保存独立不可变 manual/publication_edit 版本，保留原版本及来源；任务载荷中 originalLyrics 为原版本，lyrics 为本次实际提交文本。不会把手工改写稿标为服务商返回歌词；警告基于最终文本及确认计算。

## 发布与边界

- 统一发布载荷包含选定音频/封面文件身份、歌词原文与纯文本、来源版本、匹配确认及缺失/损坏警告。批次固定载荷，材料 ZIP 输出原稿、发布歌词和载荷 JSON。
- 腾讯本地任务保留该统一载荷及经用户确认的正式歌词。真实页面仅核实上传首屏，后续字段、草稿保存/回读未校准，生产契约保持 false；不声称腾讯已接收封面或歌词，不执行上传、签约模式或审核提交。

## 验收

隔离测试覆盖真实格式图片接收、重选、损坏/缺失/非方形、错歌曲/请求/工作区、幂等冲突、上下文变化、重启、歌词清理/来源/确认失效、材料与腾讯本地载荷。构建、类型检查、Core/inbox/TME 回归和一次隔离桌面视觉验收；不反复打开用户桌面客户端，不替换桌面版本。仅当前独立仓库本地提交，不推送、不新增软件/凭据/付费调用。
