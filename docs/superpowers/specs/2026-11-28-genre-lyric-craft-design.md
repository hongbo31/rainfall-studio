# 按曲风提升 AI 作词能力

## 用户目标与本轮判断

用户希望专业作词判断参与 AI 作词升级，认为现有歌词水平不足且不同风格应有不同表达；用户把具体方法交由团队判断。当前源码已有生成、五项评分、限次改写及最佳稿选择，但通用提示缺少曲风差异、逐句诊断和修改优先级。未取得真实失败歌词样本，本轮针对可见规则缺口升级，不宣称已证明真实成曲质量提升。

## 采用方案

在现有共享 Core 流程中增强生成、评审、改写的专业规则。xb 根据用户委托选取这个范围：保持现有调用阶段和用户设置的改写次数，让每一次调用有更明确的写作任务。

另两个方向暂不采用：增加多模型作词人/评审团会增加调用与费用；给每个曲风套固定歌词模板容易同质化，也不适合混合风格。示例曲风是参考方向，由模型按创作要求选择，不做硬编码分类。

## 写作标准

- 先明确谁在对谁说、具体处境和核心情绪；把主题落实到动作、物件、对话或感官细节，避免每句都堆意象，也保留直白表达的力量。
- 段落承担不同作用：叙事可以推进事件，抒情可以推进态度或视角，氛围作品可以有意循环。非重复段落避免只换词复述；副歌、短句循环等有效重复不被误罚。
- 记忆点可以是核心句、回环句、态度、节奏型或意象，不要求所有歌都有副歌。句长、自然语音重音、换气、韵脚与密度服务情绪；不用固定字数替代可唱性，不为押韵扭曲语序。
- 曲风适配示例：流行/抒情关注容易听懂的核心句与情绪层次；民谣/乡村重具体生活经验；DJ/舞曲人声重短句、重复、呼应与留白；说唱重语流、节奏组织、自然内韵和内容推进；摇滚重清楚立场与有力度的可唱语句；国风/戏腔重语境和意象一致，避免堆古风词；R&B/爵士等按措辞弹性与气口安排；催眠/助眠人声允许低起伏、温和重复。它们是倾向，不是子风格的固定结构。
- 指定语言和方言优先；按实际语言处理习惯表达、重音/声调和韵，不把普通话词序机械替换成方言词。没有旋律时只检查文本节奏风险，不声称已经实现词曲配合。
- 乐器、编曲和音色说明归入 style 或简短制作标注，不能挤占可唱正文；不把标题的“爆款/年份”等营销后缀强塞进歌词。

## 评审与改写

沿用 styleFit、narrative、naturalness、singability、hook 五项及现有分数/阈值。narrative 表示叙事或情绪/意象发展，也认可有目的的循环；hook 表示全曲记忆点，不以缺少副歌自动扣分。按创作要求评判，不以自己的风格偏好改写歌曲。

评语引用当前稿的具体词句，解释问题及对本曲风的影响，并给出优先修订方向；同时说明值得保留的亮点。有明确问题时不能只说“感染力不足”。文本评分不能评断未听到的旋律、演唱或乐器表现。改写以原底稿与具体意见为依据，先修关键问题，保留有效内容并逐项回查，不用无关新意象替换整首，也不为了分数制造无必要改动。

## 接入与兼容

- 仅 AI 作词页面及计划 AI 作词节点共用的 LyricWritingService 中新建人声任务启用版本化规则；纯音乐继续只输出双歌名与 style，灵感生成也不被加上歌词步骤。
- 新内部版本在估价前设置并持久化，read/list 不透出；无标记旧任务保持原提示。沿用原稿的 retrySource 继承来源版本（包括旧版缺省），恢复不临时换规则。
- 新提示在当前调用估价和后续评分/改写预留中计入字节开销；不增加调用阶段或改写上限。实际改写次数仍随评审结果变化；输入 token 会增多，费用按既有估算，不能承诺费用完全不变。
- 保留本轮此前的歌名规则、历史标题避重、已存歌词、JSON 字段及曲风/语种边界。旧的 ProviderTextService 通用创作路径不在本次 AI 作词模块范围。
- 浏览器和 Windows 共用 Core；不启动可见窗口、不读写正式库、不调用收费服务、不打包切换桌面。

## 依据与适用边界

- [Pat Pattison：Prosody](https://www.songwriting.net/blog/bid/57631/songwriting-lyric-writing-tip-prosody)：结构、行长、韵式与节奏应共同服务歌曲的中心情绪。
- [Berklee：Natural Music in Language](https://www.berklee.edu/berklee-now/news/berklee-riffs-natural-music-in-language)：自然语言重音与有目的的节奏变化可以帮助表达和记忆；英文例子不直接作为汉语声调规则。
- [BMI／Jason Blume：The Top 5 Lyric Pitfalls](https://www.bmi.com/advice/the_top_5_lyric_pitfalls1)：具体细节、后段推进、修订弱句有助于表达；并非每首歌都必须讲故事。

上述来源支持共通写作原则；曲风分组是本项目的编辑设计，非来源对所有子风格的硬性规定。不复制歌曲歌词或把热门作品导入提示。

## 验收

1. 模拟人声任务请求包含对应阶段的专业指导，生成/评审/改写格式、阶段和改写上限保持兼容。
2. 无标记旧任务、旧稿重试、纯音乐和灵感流程不受新歌词规则影响；内部版本不泄露到返回值。
3. 估价、领取和恢复使用同版本；后续预留包含新增系统提示字节。
4. 保留当前标题未提交改动。实际歌词质量需要后续在相同输入/模型下比较新旧稿，并结合成曲试听验收；mock 测试不能证明艺术质量。

## 后续真实样本怎么判断

以相同题材“夜班回家”和同一文本模型比较各风格，比较表达本身，而非只看 style 字段或模型自评分。

| 场景 | 读者可以直接判断的结果 |
| --- | --- |
| 流行/抒情 | 有容易理解、得到前文支持的核心句；情绪有具体来源。 |
| 民谣 | 叙述者可信，有生活观察；下一段带来信息或感受变化。 |
| DJ/舞曲人声 | 词句与预期人声用途相称，有节奏呼应与器乐留白；允许完整唱段。 |
| 说唱 | 内容推进与语流同时成立；没有为了押韵扭曲语序或空喊态度。 |
| 国风/戏腔 | 语体、人物关系和意象一致；没有古风词堆砌，不强制七言或戏腔。 |
| 助眠人声 | 低信息负担、平稳语气与有意循环成立，未被评审强改为剧情冲突/高亢副歌。 |
| 粤语等明确语种 | 词义与语体自然，不以口语助词数量判断地道；实际协音留给成曲听辨。 |
| 一轮改写 | 评语指向当前稿的具体位置；被指出的关键问题得到修订，原有亮点及其他有效段落保留。 |

真实样本生成与试听未在本轮执行；这张表是后续验收标准，不是本轮实测结果。
