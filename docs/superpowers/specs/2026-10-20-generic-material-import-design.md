# 通用素材导入设计

目的：普通用户把每首歌的 lyrics.txt、style.txt、cover.png/jpg/jpeg 放在各自目录中，即可预览、确认标题后入库，无需手写 JSON。保留现有100首索引适配；高级用户可选 rainfall-materials.json 明确相对路径。

扫描与入库是两个动作。扫描只建立可修改的预览，不改变已入库素材、作品或队列。预览展示真实文件、歌词/Style、封面和校验问题。目录名/manifest标题是待确认标题；缺失/多封面/路径问题必须手动选文件或修改标题后重新校验。确认入库重新验证预览指纹和来源版本，拒绝扫描后文件变动。

歌曲以来源ID和稳定 sourceKey/明确历史绑定识别，不以歌名合并。复制内容只提示重复，明确接受后创建独立 UUID。重扫更新保留 UUID、音频版本、作品及发布历史；新内容增加 revision，不能改写旧作品的托管封面快照。根目录迁移通过单独的系统目录选择、预览和确认重新绑定；不按相似目录自动合并。

所有路径都必须在所选根目录中，禁止绝对路径、越界、链接/重解析路径及危险遍历。扫描遇权限或不可读文件要显示错误，不能猜配或静默覆盖现有记录。设置文件/预览仅写隔离应用数据库，素材源只读。批量及资源限额避免无界扫描。

保持正式客户端、生产数据、自动收件和旧Demo不变。不调用真实/付费API、不生成/上传/发布、不取聊天凭据。真实费用上限和番茄正式写入能力仍门禁阻止。

交互：选择来源→扫描预览→逐行查看/修改标题与角色文件→显式确认标题及重复项→确认入库。已有来源提供“重新绑定目录”进入同一预览流程。关闭/取消预览不改变素材。模板包含一首空目录，中文说明解释普通布局、可选manifest、重复/搬迁及历史规则。
