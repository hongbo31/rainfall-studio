# 安全、发布预检、UI 与验收

## 安全边界

资产与作品是本机私人数据；renderer 不接触 OS 权限和令牌。主进程校验 IPC senderFrame 是受信 app://ui/、验证 schema/当前 workspace/account；不允许第三方 iframe、任意导航、新窗口、webview。CSP 禁止外部脚本/CDN，生产不允许 unsafe-eval。主进程只允许配置内 providerId 打开官方 HTTPS 入口。

OAuth 用系统浏览器；回调采用该平台批准的方案，state/nonce 一次性并限时，PKCE 仅在官方明确支持时用。不能自行读取登录浏览器 cookies 或配置文件。抖音 client_secret 需要服务端 broker；不得存进 EXE、renderer、localStorage 或普通配置。未部署获批 broker 时正常显示接入阻塞。

允许本地保存的用户级凭据使用 Main Electron safeStorage（Windows DPAPI）加密，密文加 accountId/providerId/remoteSubject 绑定并存独立目录；解密失败阻塞账号，绝不明文降级。DPAPI 不能防同一 Windows 用户下的恶意程序，本机角色也不构成 OS 安全隔离。适配器拿到最小范围短期凭证或 broker session，Renderer 永远只见授权状态/到期时间/脱敏身份。退出登录吊销或删除密文，暂停相关未提交任务，历史审计保留去标识引用。

导入文件先复制 staging、限制大小/像素/格式、可信探测；FFmpeg 用参数数组、shell:false、-nostdin，只允许受管本地输入，禁止从媒体文件引用网络协议；写输出用工作目录 token。字幕/歌名不直接拼过滤器表达式，优先先渲染本地文本图层或使用安全转义的文件输入。测试含 &、引号、换行、中文、emoji、CON、..、UNC 与 reparse point。数据路径正规化后再做根目录边界检查，不以字符串前缀替代真实路径验证。

敏感日志脱敏前置于 logger，覆盖 headers、URL query、errors、nested JSON、broker 响应；只记 request hash、平台错误码、状态与字节数。默认无遥测、无远程日志、无自动崩溃上传。凭据/媒体/用户备份/QA browser profile 都在 .gitignore。审计导出也不包含密钥和完整作品。

## 预检矩阵

预检每个 target 单独执行；共同文件可复用探测，但不能把一平台通过推及全平台。RuleSet 带 adapter/API profile、版本、官方证据链接、checkedAt、约束、AI支持；超过30天未复核或缺关键约束时提示 rules_stale/unknown，禁用自动真实 commit，允许人工材料准备。30天是本产品审慎复核周期，不是第三方规定。

| 类别 | 必须检查 | 失败行为 |
|---|---|---|
| 文件 | 音频/封面可读且 hash 匹配快照；真实解码；容器/编码/采样率/声道/时长/大小；封面尺寸/宽高比/格式 | missing_asset、corrupt_media、rule_mismatch；能本地转码则明确生成新派生资产，不能静默覆盖原件 |
| 视频 | 抖音 video_post 必须有完整可播放 MP4；音频+封面包装参数、画幅、码率、时长、安全区与来源 | 音频或图片不能当视频上传；缺 FFmpeg 阻塞视频准备，其他任务继续 |
| 内容 | 歌名、艺名、作词作曲/演唱/制作 credits、语言、是否纯音乐、歌词/无歌词声明、专辑次序、发布日期/时区 | 缺字段阻塞；无歌词不是自动填造歌词；长文案按目标验证 |
| 权益 | 录音、词曲、封面/字体/参考图、生成平台商用依据、授权期限/地域/独占、合作演唱/人声许可；附件存在与人工声明 | unknown/expired/territory_conflict/exclusive_conflict 阻塞真实发布；勾选声明不自动证明权利已成立 |
| AI | 音频/歌词/封面/视频分别 none/assisted/generated/unknown、来源平台/生成日期、需要的显式标识与元数据映射 | unknown 阻塞；目标所需 AI 字段无法通过获批 API 表达时 manual_required，不通过标题加字假装满足全部规范 |
| 身份 | route 账号、remote subject、艺名归属、scope、token有效期、应用审批、平台资格 | auth_required/approval_required/identity_mismatch；不能登录成功就放开发布 |
| 防重 | 同快照幂等 key、现有 target claim、已有外部发行/未知提交、路线目标重叠 | duplicate/inconclusive 阻塞或跳过并链接历史，不重新创建远端作品 |
| 执行批准 | 快照 hash、批准范围、可见性/发布时间、费用上限、批准时效和撤销状态 | approval_missing/stale；具体清单确认后才能传输/提交 |

RightsRecord 是证据管理，不提供法律认证。正式发布前由用户核验商用权益与平台当期规则。应用不自动接受新发行合同、独占授权、平台条款或付费协议。

## 实际视频包装

首版内置工作预设：1080×1920、30fps、H.264/yuv420p、AAC 192kbps；方形母版在竖画布按 contain + 背景留白，歌名/艺名来自排版图层；默认完整音频，不默认截短、淡出或增加第三方音乐。该预设仅用于本地视频草稿，最终以选定平台 RuleSet 为准。UI 显示音频起止时间，剪辑必须用户选择；视频时长与选段误差≤100ms或一帧的较大值。

调用 ffmpeg 生成临时 MP4，解析 progress 与 ffprobe 验证实际流、尺寸、时长和音轨；仅校验通过后入库并标“本地视频已完成”，不能标“已发布”。原文件/来源元数据保留，派生处理可能不能保留所有第三方真实性元数据，记录转换谱系并提示人工核验；不伪造水印/C2PA 证明。

## UI 沿用与新增流程

保持 Rainfall Studio 暂定名与原型已有中文文案、深色暖紫、左导航、中央创作/作品、底部播放器，复用现有 CSS 变量、间距和截图。首页数字来自真实本地数据库，演练数据有持久水印，生产环境不自动注入模拟播放/收藏数。

1. 作品库新增列表/卡片切换与复选框，筛选艺名、系列/专辑、生成源、素材完整度、发布状态。Shift多选/全选仅当前筛选集合，显示“已选 N 首”，不静默包含隐藏项。无音频作品仍可看/编辑，批量发布明确阻塞。
2. 选择后浮动工具条“批量发布”，打开工作流抽屉：目标平台、每平台账号/艺名、发行路线、音频/视频类型；抖音行明确“需制作视频”，可以打开本地包装预览。
3. 预检呈作品×目标表，每格显示可执行/缺素材/待授权/需人工/重复；点格查看字段级修复。显示将执行单元数、费用已知/未知、需人工项数量；不通过的不能勾入真实执行范围。
4. 确认页展示歌名、实际文件版本、艺名/账号、平台、视频预览、可见性、日期、权益和 AI 声明摘要、费用上限。按钮写“确认并发布 N 项”；本轮无真实授权，开发/验收只能点“开始演练”或“导出材料包”。模拟与真实不能混在同一批。
5. 发布中心双维度：每首×每平台概览、按实际提交单元的详细日志。只有失败项显示安全重试；UNKNOWN 显示“核对投稿”；未提交显示取消；已提交展示远端回执/审核时间与来源；人工结果标“用户录入”。
6. 账号设置内提供独立艺人资料与账号列表，经显式绑定建立映射；艺人默认曲风、人声、歌词语气、BPM范围和封面风格可编辑，作品显示继承来源与覆盖。身份资料、授权状态、发布/数据权限、开发者审批分别显示。不同账号凭据/配额不能串用，不能凭输入名字伪造授权，不创建参考材料中的管理员身份。
7. 封面工作室增加真实文件库版本、无字母版/排版衍生、规格预设版本来源；Codex 入口仍是任务交接。音乐生成入口可打开官方页面并导入，不把手动流程写成已自动生成。
8. 编辑草稿500ms去抖写库，显示“保存中/已保存/保存失败”；切页/退出有未落盘内容时 flush；磁盘失败时保留编辑内容并提示。版本比较保存快照，不靠失焦偷偷新建版本。

9. 创作页分“手动创作/每日计划”两入口。计划显示时区、下三次运行、应用需打开、候选/费用上限及成品目标；错过运行不自动追补。总览分别显示成本/候选、成品进度、账号投稿配额。
10. 任务与发布中心内置异常筛选/抽屉，显示失败步骤、已有素材、已花费/预占/未知成本、远端提交结果和安全恢复动作。审核通过、提交成功、已上线三列分开，未知不能隐藏。
11. 检查点设置默认本地自动准备、发布人工确认；首版发布确认不能关闭。付费生成授权明确账号/计划/时限/金额，不能由开启日计划自动获得。

详细行为和8组验收见 [补充规则](artist-planning-controls.md)。增加调度DST/离线/重复tick、原子多桶预占/跨日/晚到结算、绑定权限与逐步恢复测试；断言自动发布契约不可调用、成功生成步骤重试调用次数不增。

键盘/可访问性：复选框具标签、表格可键盘导航、焦点可见、状态不只靠颜色、弹窗焦点回归、screen reader 状态更新节流。最小桌面窗口1100×760，测试1280×720缩放/高DPI可滚动；低高度侧栏不能遮导航；200% Windows 文本缩放检查。保留原型390px视觉作为参考，正式桌面不把移动布局视为主要交付。

## 验收分级与证据

- unit/integration：事务、schema迁移、hash导入、版本冲突、账本、队列 transition/幂等/未知处理、CSV累计口径。
- contract：本地 HTTP stub + 正式文档 fixture；注入 401/429/5xx/超时/乱序；真实 adapter 仅证明解析与请求构造，不标 live。
- e2e：Playwright Electron 驱动实际窗口；从打包 EXE 再验证导入音频→退出重开→试听→选多首→预检→模拟批发布→部分失败重试→未知核对→备份恢复。独立 QA userData，禁止操作用户真实库。
- security：renderer 无 Node、IPC schema/来源、路径越界/ZIP slip、伪造 approval、模拟 transport 不触网、凭据日志扫描、恢复不会重发、未知提交不能重试、外部URL白名单、跨艺名/账号拒绝。
- visual：1440×1000、1280×720、Windows 125%/150%与200%文本；总览/库多选/预检/发布网格/未知状态/封面/账号截图；无裁切、底部播放器不遮关键操作。
- package：真实 EXE、Setup.exe、SHA256、依赖锁/许可证、原生 SQLite 解码自检、无系统 Node 环境启动测试；隔离环境可用则安装/卸载/升级保留数据。没有环境则据实记录未验安装。

最终报告逐项标 executed-passed、executed-failed、not-run-blocked、contract-only、live-verified。必须保留真实日志/截图，不以此设计文档代替测试结果；禁止为了过测 mock 文件播放或把未知审核写成成功。
