# 0.10.0-preview.1：计划中心接通已有服务

本版本在独立 Windows 验收仓库继续开发，没有更新正式桌面快捷方式、正式安装指针或原业务数据。接通的是已安装适配器和持久化工作流；所有本轮外部响应均来自隔离夹具，未进行线上生成、扣费、条款接受、上传或发布。

## 已完成的路径

- 计划的最终评分稿交给原 ProductionFlowBroker 和 YourMusicAdapter，复用生成、原任务 ID 查询、下载、媒体验证及 A/B 作品存储。Suno 官方接口另行保留，未冒充官方直连。
- `chirp-v6`、`chirp-v6-wild`、`chirp-v6-mini` 来自已安装接口契约。账号历史证据通过已有 history GET 读取最近 20 条，按 profile/revision 隔离并保留 24 小时。历史成功不表示当前可用；换 key 或清 key 先失效缓存，锁阻止迟到的旧账号响应复活证据。
- 音乐预算和已有积分授权可配置。预留数值不是供应商报价；未核实实际成本时保持预留并冻结后续提交。unknown 不自动重发，重试沿用原 child/operation。
- “绑定已有音频”仅允许 manual 快照，校验作者、最终标题/歌词、实际文件和哈希。保留原始 A/B，B 选择贯穿歌词确认、发布材料和条款待确认列表。付费路线拒绝手动绑定，防止另建作品后意外提交。
- 接收的精确封面可绑定同一作品；歌词被改写时要求更新封面。材料确认记录实际音频/封面/歌词哈希、作品修订及用户授权说明，供应商许可仍标为未验证。
- 每项、每平台、每账号映射同一持久化发布任务。原 TME 准备/提交/回读路径按 task/account 隔离；原生操作锁保持到实际操作结束。线上完成必须具有匹配当前账号身份的可信回执。
- dot 生成持久化 requestId/requestHash 和完整 Plan/Run/Item/身份快照，v2 回包必须精确 echo。停止、过期和迟到结果仍可收件并关联，不启动后续业务。

## dot 文件桥

只使用用户已授权且启用的桥目录。请求投影为不可变文件：

`requests/plan-requests-<12 位递增序号>-<contentHash>.json`

producer 应读取本工作区、本 owner、schema/hash 完整的最高序号世代，只处理 `requestStates=pending`。没有可覆盖的 HEAD 文件；停止等状态变化生成新世代。owner 和世代 reservation 先单独持久提交，随后独占发布，崩溃后可重试；现有 foreign 文件不覆盖。事务内投影明确阻塞。外部 dot 执行仍由父会话协调，本应用没有虚构触发 API。

## 仍有实际阻塞

| 能力 | 当前边界 |
|---|---|
| 账号当前模型权限/余额/准确报价 | 没有可信实时目录或报价端点，历史记录不能替代 |
| 真实专辑目录、新建专辑、追加专辑 | 现有 `save_album` 仅本地材料快照；远端完成证据不足，明确 blocked |
| 全平台无人值守发布 | 没有此能力；网易云、汽水、抖音等缺少已验证执行器，音频发行与抖音视频独立 |
| TME 多账号同时在线会话 | scope 已隔离，底层仍受现有会话与权限限制，未做线上验收 |
| dot 外部执行 | 本地协议和投影已实现，外部 producer 需按上述契约实现并回传精确 echo |
| Codex 自动图像 API | 未提供；保留辅助工作流、请求导出、导入和版本选择 |

独立复核已关闭本轮发现的 P1/P2。便携包使用 Node 模式检查 Core、SQLite ABI、相对数据路径和依赖闭包，验证记录随候选包交付。本轮没有启动 Electron Main GUI，因此未声明打包客户端原生视觉验收或线上接入验收完成。

开发启动：已有依赖环境中运行 `npm run desktop:dev`。该命令会打开 Electron，本阶段没有执行它。

便携候选：解压整包后运行 `RainfallStudioCandidate.exe`，默认数据保存在可执行文件旁的 `candidate-data`，与正式数据隔离。整个目录必须保留。候选包没有绑定账号、附带凭据、安装器或开机任务；本阶段仅以 `ELECTRON_RUN_AS_NODE=1` 验证包内 Core，不等同于原生 GUI 或线上验收。
