# 0.12.0-preview.7：配置复用与自动化衔接

## 使用

- 配置中心按平台保存账号、艺人和默认参数。番茄点“登录并同步资料”读取并保存官网艺人名单；不会用登录昵称覆盖已有署名。其他平台的已接通能力以页面状态为准。
- 发布中心选作品、选平台、点“发布”。歌词、封面和选定音频取自作品；番茄自动准备副本、检查重复、填表。签约偏好复用配置，最终合同和短信验证仍由用户完成。
- 封面页点“自动收图”，把一张方图保存到显示的目录，命名 cover.png、cover.jpg、cover.jpeg 或 cover.webp。目录内 request.json 包含提示词，适合外部生图工具对接；客户端自动接收并匹配作品。
- 计划中心支持每天北京时间 09:00、10 首独立歌曲、选择 A 并保留 B。音乐可选“不限积分”，不自动充值。开启自动上传前连接一次番茄并保存计划。
- 后台运行设置可选择关窗后继续执行、登录 Windows 后启动。电脑关机、休眠或断网时不能保证准时运行。
- Windows x64 便携包解压后运行 RainfallStudio.exe，整个程序目录需保留。默认数据在 %APPDATA%/RainfallStudio；新设备自行填写服务密钥、登录 Chrome。无需 Node/npm/Codex，媒体处理工具随包提供。

## 已验证

2026-11-12，本机实际打包客户端完成：

- 空白数据目录启动、创建独立测试作品、1440 方图自动收取并显示、关闭窗口后台存活、退出重启后保留作品和后台设置。
- 程序目录搬移后使用包内 ffmpeg/ffprobe 转换和读取音频。
- 从真实番茄官网同步两位艺人、完整读取三首审核中作品。正式记录保持原 ID；选两首本地作品点击统一发布按钮，均因官网已有同名记录跳过，没有重新上传或签署。
- 封面及发布界面在 760、1080、1440 宽度无横向溢出，主要操作按钮高度一致。
- 测试夹具验证：09:00 只创建一次十项任务；A/B 音频收取、自动 A 选择、材料检查、番茄持久队列和回执衔接；未知结果不自动重发；改账号、配置、素材或停止任务时阻止继续写入。

## 尚未验证／待用户配置

- 本次没有调用付费歌词、音乐或图片生成，也没有以未上传的新作品验证新版本真实上传正向路径。队列全流程测试使用合成供应商及官网回执，不能视为真实全链路成功。
- 用户要求歌词密钥留给后续使用者填写，图片服务尚未指定。图片 API 直连接口仍待接入；现有可用路线是本地导入／自动收图目录。
- 每日十首主题未定，计划保持停用；不自动产生费用。
- 新设备验收采用同一台 Windows 的独立目录与空白数据根，未声称在第二台物理设备上验证。未实际修改本机登录启动注册来测试该选项。
- 原桌面升级须沿用 verified-desktop.json 的 dataRoot，先备份再换包；不要把便携包的空库覆盖到原库。验收证据和备份保留在本机 outputs/desktop-backup-20261112-preview7 及 outputs 中。
