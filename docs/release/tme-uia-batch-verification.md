## 当前边界

- Main 调用短时 PowerShell 7 UIA 进程，仅读取或操作用户本次选定的 Chrome/Edge 腾讯音乐人可见文档。每次动作核对进程启动标识、窗口、HTTPS 来源和可见昵称。没有 Cookie、浏览器配置或凭据读取，没有端口启用、扩展、服务或自启。
- 可见昵称不是平台唯一账号 ID。同名账号无法自动区分，因此协调器、原生传输和 PowerShell 主机三层均阻断真实写入，界面禁用上传/授权/提交按钮。用户输入 ID 或勾选确认不能绕过。连接重启后不能自动续写历史表单。授权页没有可见作品身份时不从缓存补造歌名，自动授权/提交必须停止。不会宣称平台已暴露稳定歌曲 ID。
- 本轮真实客户端验收只读。已有单曲成功提交是此前用户逐项授权后的外部正常 UI 操作，不是客户端自动提交。新代码没有再次上传或提交该曲，也没有上传其他歌曲。
- 写入通道仍为开发验证状态，不应当作已完成实站端到端验收。非本人作词/作曲、日期控件月份不同、控件变化、已有未保存表单均会停下，转官网人工核对；不会按猜测继续。自动上传的附件仅为所选原始音频，可选原创证明需在官网人工核对/补充。
- 现阶段支持现有专辑追加；共享封面不上传、不更换。独立新专辑、其他平台自动上传、推广、统计 API 均不属于本次接通范围。

## 使用路径

作品库勾选多首 → 发布中心 → 腾讯音乐人上传工作台 → 每首分别选择本地账号备注、现有专辑 ID、封面策略、版本/曲风/语种、作者/AI/歌词资料，完成当前版本预检 → 建立所选作品批次。

当前可在官网打开目标专辑，输入右上角真实可见昵称，只读识别并按歌名/专辑 ID 核对当前列表。可建立、查看和取消本地多首批次。真实上传/授权/提交按钮保持禁用。离线协调器实现为逐首上传、缺资料项独立阻塞、每首授权与提交各自确认，但尚不能用于实站写入。

批次复用 `batches/units/claims`，与通用发布批次隔离。预约与外部动作开始分别持久化：取消或重启只释放处于 `TME_RESERVED`、能证明尚未开始外部动作的预约和本次绑定；`TME_STAGING` 意图及其后状态永不据取消释放。上传/接受/提交前先持久化意图，超时或中断保留待核对状态和重复保护，禁止直接重传。跨会话只允许只读核对。取消不撤回已发生操作。未执行过的取消批次可重新建立，历史与审计仍保留。

回执分别记录专辑 ID、可空的歌曲 ID、来源、观察时间及匹配依据。“列表中看见同名歌曲”仅是可见歌名与专辑匹配，不能证明音频身份或客户端提交；成功页回执如可确认则另标本次表单提交来源。

## 为真实写入验收还缺什么

首先是代码/证据条件，不能用用户勾选替代：从正规可见页面核验稳定唯一账号标识，并在每个写动作前回读；建立当前授权页与具体歌曲/录音的可验证关联；修正空曲风/语种处理；完成对应映射测试。条件满足前保持三层写入阻断。

之后需要用户仅指定 **一首新的、尚未提交的自有验收歌曲**（不能重复当前已提交曲），提供对应原始音频、正式歌词、目标现有专辑、准确可见账号及作者/AI/日期事实。确认现有专辑封面保留。

最小分阶段批准为：先允许该唯一目标的一次上传和字段填写，停在协议前；看到实际授权模式及完整协议后，再独立批准本首协议接受；最后另行批准本首一次提交审核。任一步结果不确定先回读，不能重传。若要验收真正多首，还需第二首独立指定、预检与同等逐首授权，历史单曲同意不能复用。
