# 0.11.2-preview.2 源码发布快照

本提交以仓库已有 main 历史为基础，不导入本地开发仓库的私密历史。源码来自已完成本机原生验收的 0.11.2-preview.2，随后仅筛除本机操作文档、私有交接文件，并将测试中的账号显示字符串替换为示例。

静态包与源码一致性、已有版本原生运行验证分别记录，不据此宣称安装/卸载或全新 Windows 环境已测试。
