# 0.12.0-preview.6 — 番茄批次与授权准备

发布中心选多首作品、版本和番茄音乐后，由主进程顺序处理。批次保存在当前数据根 production/fanqie/batch.json；单项不确定时暂停后续作品，重启后不会自行重放，继续批次会重新核对账号及原有上传回执。已完成项保留，重复发布由原作品目录和音频回执拦截。

上传和授权分开保存：官网唯一新 ID 核实后先保存上传成功，再准备已配置的独家/非独家模式、个人身份和发行平台。番茄音乐为官网必选项；番茄畅听可选。已有待授权作品可在“番茄账号与已有作品”中选择多首并继续授权，按作品依次准备合同预览。当前未合并成同一合同。已进入审核等状态的作品仅回读，不重新授权。

最终合同确认和电子签验证由用户完成。程序不调用“确认签署”。已准备的页面在同一浏览器会话中复用；页面丢失时提示核对官网，避免产生重复签约。所有外部写入前重新核对账号和作品状态。
