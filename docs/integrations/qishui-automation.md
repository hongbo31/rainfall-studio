## 账号与登录

1. 使用用户指定的浏览器和账号窗口，由用户完成需要本人操作的登录。
2. 验证官网来源 `https://music.douyin.com` 和实际可见控件，不只检查 URL。
3. `/console/publish` 为发布入口；`/console/complete-publish` 为全曲发布流程。查询参数不是账号或作品身份依据。
4. 检查发布入口、作品标题框、上传完整版控件以及当前艺人。页面可访问与账号身份绑定是不同检查。
5. Rainfall 的持久档案设计为 `<dataRoot>/browser-sessions/accounts/<accountId>`。目录存在只代表档案存在，不代表已登录。不得导出 Cookie、令牌或将凭据写入文档、截图说明、版本库。
6. 复用已有表单，不在已填写或上传后自动刷新、关闭或重新导航。跨重启验收应先安排可恢复的测试状态。

## 生成与材料准备

生成前确定新作品、艺人、歌词、风格、声线和版本；不重放已提交歌曲。使用收费渠道前确认额度范围。本次授权为使用已有额度生成一次、通常两个候选，不充值、不自动付费重试。

生成提交结果不明时，不再次提交：保留发出记录，先只读查询历史，通过歌名、完整歌词、模型和发出时间共同匹配，再恢复原任务。任务编号、音频及费用状态分别记录；音频生成成功不证明费用已核对。

根据本次官网页面要求：

| 材料 | 页面要求与核对方式 |
| --- | --- |
| 完整版音频 | WAV 或 MP3，不超过 200MB；采样率不低于 44.1kHz，双声道；页面另写位深不低于 16。MP3 元数据的 bits_per_sample=0 不能当成 16 位证据，保留原始检测结果并观察平台反馈 |
| 封面 | JPG、JPEG 或 PNG，至少 1440×1440，不超过 10MB |
| 歌词 | 文本框上限显示 10000；上传前区分生成提示中的段落标签与正式歌词。整首实际演唱一致性仍需试听核对 |
| 授权证明 | 页面支持 ZIP、JPEG、JPG、PNG、BMP、PDF，不超过 200MB；独家代理发行页面提示必须提供。不能因首步可继续就认定可省略 |

文件路径、哈希、版本、尺寸和音频属性应在操作前绑定。本次封面经用户明确同意从 1254×1254 等比例放大为 1500×1500，仅改变尺寸，不宣称增加原生细节。

## 首步表单与上传

1. 阅读当前表单，确认只操作目标歌曲卡片。多个歌曲卡片不可按全页第一个同名输入框填写。
2. 根据实际制作方式选 AI 创作。本次选“是”，AI 工具为 Suno。词曲署名由用户指定，不能从默认表演者自动推断。
3. 填歌名、表演者、曲作者、词作者、纯音乐选项、曲风、歌词与专辑信息。歌名不能附加平台不允许的版本或表演者后缀；版本另行记录。
4. 当前页面中 AI 与纯音乐的“是／否”重名。需根据当前 DOM 的所属区域定位，不能固定使用全页第一个“是”。本次 `getByLabel` 对 AI 区域未匹配，改用当次观察到的控件属性完成；动态属性不能跨页面硬编码。
5. 三个“添加自己”分别对应表演者、曲作者、词作者。本次先校准字段顺序，再分别操作并回读。后续代码应按字段容器定位，不固化序号。
6. 文件选择：先监听 `filechooser`，再点击当前页面确认的上传控件，取得选择器后传入指定绝对路径。封面出现“调整图片”弹窗时，确认裁剪属于上传操作，不等于提交发布。
7. 上传后必须看到文件条目、封面预览和检测结果。汽水可能自动生成剪辑版并识别曲风；读回这些副作用，避免重复上传。
8. 歌名在本次单曲表单中同步成为专辑名。不得推广为所有多曲专辑均自动同步。
9. 用户授权进入下一步后才点击，核对页面确实进入“授权作品”。按钮执行成功不等于发布成功。

## 授权作品与停止边界

本次页面提供三种模式，均为三年：

| 模式 | 页面显示的主要范围与限制 |
| --- | --- |
| 独家代理发行 | 字节系 APP 与其他 150+ 全球流媒体；授权期间不可自行转授权其他平台 |
| 独家授权 | 汽水及抖音系 APP；授权期间不可自行转授权其他平台 |
| 非独家授权 | 字节系 APP；授权期间不可与其他平台签独家协议 |

这些是本次页面摘要，不代替后续实际合同。用户本次明确选择“独家代理发行（3年）”；发行范围保持页面所示“全球”。选择卡片不是签署协议。默认选择不得自动视为用户决定。

授权信息还显示其他平台音乐人主页链接，本次为“本次测试艺人／QQ音乐／无主页链接”。这是页面现值，不证明艺人在其他平台没有主页；后续提交前应按真实信息核对。

历史验收曾停在选择授权模式。用户后续明确要求继续授权、接受合同，直到最终签署验证码处停止。客户端展示当次合同并收集针对当前内容的确认；接受后只识别验证码控件，不读取短信、不填验证码、不点击最终签署提交。确认与账号、作品、页面和合同内容绑定，五分钟失效，不持久化、不重复使用。

## 浏览器超时与恢复

本次桌面日志出现 `No ChatGPT browser route is available for browser session`。这是路由连接层的故障证据，不足以断定网站登录失效。重置工具会话、选择已有内置浏览器、按标签页 ID 绑定，再通过 DOM 快照读取，曾恢复成功；之后仍有超时，不能称为彻底修复。

- 保留当前浏览器与页面，优先用已支持的会话恢复和标签页定位；不复制登录数据，不绕过安全检查。
- 一个调用多次读写累积超过默认 30 秒会导致工具内核重置。本次多次单操作约需 21～22 秒；拆分有依赖的操作，必要时设 60 秒工具超时。
- 文件选择器 10 秒监听曾超时；检查页面无上传结果后，改为 60 秒监听成功。写操作超时应先核对结果，再决定是否重试。
- 截图失败时保留此前证据，并记录新的 DOM 选中标记；不得声称新截图已成功保存。
- 后续聊天需要继续操作时，保留标签页交接标记；不要关闭含未提交材料的表单。
